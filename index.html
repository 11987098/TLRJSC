1 软件概述与轴定义

1.1 软件功能

本软件根据凸轮成品尺寸（可由 DXF 自动识别或手动输入），自动计算粗磨（分层进刀）→ 圈边（每圈进刀）→ 光磨（无进给抛光）三阶段走刀轨迹，并生成对应数控系统的 NC 加工程序。生成过程中自动完成：

  • 砂轮磨损补偿（修砂轮量自动计入 X 坐标）；
  • 修砂轮调度（按时间 / 按圈数 / 精磨前集中修砂轮）；
  • 尺寸校验（圆角半径、内切圆、毛坯直径等约束）；
  • 每圈最大切削量约束（粗磨分层进刀、圈边每圈进刀，逐圈不超过设定进刀量）。

1.2 机床轴定义（与 NC 程序一致）

轴含义说明
X砂轮架径向进给控制磨削深度；输出支持直径编程 / 半径编程两种口径（见 5.4）
Z轴向（宽度方向）走刀圈边阶段沿 Z 轴走刀（可选，Z 起止相等则不启用）
C工件回转凸轮轮廓角度坐标（0°～360°）

加工平面：默认 G18（XZ 平面）。

3 快速上手（标准流程 6 步）

1
启动软件
双击「凸轮磨削NC程序生成软件」图标（或运行主程序）进入主界面。软件自动恢复上次保存的全部参数与程序代码。
2
导入凸轮图样（可选）
在 ① DXF 文件 卡片点「选择 DXF」选择凸轮图样（*.dxf），再点「读取并识别」。软件自动识别 D、L1、L2 并填入尺寸区。也可跳过此步直接手动输入尺寸。
3
选择形状并设置尺寸
在 ② 自动识别尺寸 卡片选择形状（标准腰形 / 标准圆角矩形 / 标准正多边形），核对 D、L1、L2（多边形为 Ø内切圆 L2）、R、N，选择 L1 方向（横向 / 竖向），点击「应用尺寸 / 重新预览」。
4
设置补偿与磨削参数
在 ③ 补偿 填入 L1/L2 补偿（负=磨小）。点击绿色按钮切换到磨削参数布局，在右栏设置粗磨/圈边/光磨的进刀量、速度、C 轴步长、光磨圈数，以及精磨预留、圈边余量、Z 轴走刀、定时修砂轮、编程方式等。
5
设置砂轮与输出
在 ④ 砂轮模块 确认砂轮当前实际直径（修改需密码 123456）；在 ⑤ 输出模式/数控系统 选择宏循环或全展开，勾选「允许修改系统」后选择数控系统，确认 NC 程序名。
6
生成 NC 程序
点击中栏底部蓝色大按钮 「▶ 生成 NC 程序」：确认对话框 → 选择输出目录 → 软件写出 NC 文件并自动更新砂轮直径。查看底部日志确认结果。

4 中栏参数面板 —— 逐控件详解

中栏自上而下为 ① DXF 文件 → ② 自动识别尺寸 → ③ 补偿 → ④ 砂轮模块 → ⑤ 输出模式/数控系统 → 生成按钮。每张卡片标题栏带 ▼/▶，点击可折叠/展开。中栏可滚动（滚轮或滚动条）。

4.1 ① DXF 文件

4.1.1 文件路径输入框

控件类型文本框（Entry）
界面位置中栏卡片① 左侧，占卡片大部分宽度
默认值空（未选择时）
单位—（路径文本）
功能说明显示已选择 DXF 文件的完整路径，也可直接手动输入路径。
操作方法点击「选择 DXF」自动填入；或直接点击输入框键入路径。
注意事项读取前文件必须真实存在且为有效 DXF；路径含中文/空格均支持。

4.1.2 「选择 DXF」按钮

控件类型按钮
界面位置卡片① 中部
功能说明打开文件选择对话框（标题：选择凸轮 DXF 文件；过滤 *.dxf 与所有文件），选择后路径自动填入输入框。
操作方法点击按钮 → 浏览到 DXF 文件 → 打开。
注意事项本按钮只选择文件、不读取；需再点「读取并识别」才会识别尺寸。

4.1.3 「读取并识别」按钮

控件类型按钮
功能说明读取 DXF 文件并自动识别凸轮尺寸：D（原料直径）、L1（凸轮长度）、L2（凸轮宽度）；识别结果自动填入 ② 区尺寸输入框，识别过程与结果写入底部运行日志。
操作方法选择有效 DXF 后点击；识别成功则尺寸自动填入，状态栏更新为「已识别 D=…，L1=…，L2=…，孔 N 个」。
注意事项① 未选择有效文件时弹出提示「请先选择有效的 DXF 文件」；② 识别失败弹出错误说明；③ 异形（非标准腰形）凸轮按识别出的 L1/L2 以标准腰形轮廓生成，DXF 实际轮廓点仅用于尺寸识别（日志会提示）。

4.2 ② 自动识别尺寸（识别后可手动修改）

4.2.1 形状选择（三个单选按钮）

控件类型单选按钮组（Radiobutton × 3）
选项① 标准腰形（长圆形）　② 标准圆角矩形　③ 标准正多边形
默认值标准腰形（长圆形）
功能说明切换凸轮几何类型。切换后：尺寸输入项按形状自动显示/隐藏（见下表）；L2 标签随之变化；形状说明文字更新；预览立即重绘。
注意事项圆角矩形：显示 D/L1/L2/R；正多边形：显示 D/L2/R/N（L1 不参与几何，自动对齐 L2）；腰形：显示 D/L1/L2（R、N 置灰）。
形状几何定义参与尺寸说明
标准腰形（长圆形）两段半圆 + 两段直线D、L1、L2L1≥L2；L1<L2 时应用尺寸时自动对调
标准圆角矩形矩形四角倒圆角D、L1、L2、R切点跟踪等距磨削，与腰形同算法
标准正多边形内切圆控形 + 角部圆角D、L2、R、NL2=内切圆直径（对边距离）；R=角部圆角；补偿用 L2 补偿等向缩放

4.2.2 D 原料直径

控件类型数字输入框（Entry）
默认值14.2000
单位mm
功能说明毛坯圆料（棒料/圆盘）直径。预览中蓝色外圆即按此值绘制。
操作方法直接输入数字；可含小数。
注意事项必须为正数；应大于成品最大外形尺寸 + 粗磨留量，否则轮廓会超出圆料（应用尺寸时报错）。

4.2.3 L1 凸轮长度

控件类型数字输入框（Entry）
默认值13.0000
单位mm
功能说明腰形/圆角矩形的长边尺寸；正多边形时不参与几何（自动与 L2 对齐）。
操作方法直接输入。
注意事项必须为正数；L1<L2 时点击「应用尺寸/重新预览」会自动对调两值。

4.2.4 L2 凸轮宽度 / Ø内切圆 L2（对边距）

控件类型数字输入框（Entry）
默认值8.0000
单位mm
功能说明腰形/圆角矩形为短边宽度；正多边形时切换为「Ø内切圆L2（对边距）」，即内切圆直径（对边距离），直接控制多边形大小。
操作方法直接输入；正多边形时该标签加宽为「Ø内切圆L2（对边距）」。
注意事项必须为正数；正多边形 R 必须小于 L2/2（内切圆半径）。

4.2.5 R 弧尺寸

控件类型数字输入框（Entry）
默认值1.0000
单位mm
功能说明圆角矩形 / 正多边形的角部圆角半径。正多边形角部由 R 圆角控制（切点跟踪等距磨削）。
操作方法仅圆角矩形/正多边形可编辑（腰形时置灰）。
注意事项正多边形 R 必须 ≥0 且小于 L2/2；R=0 为尖角多边形；R 为负值报错。

4.2.6 N 边数

控件类型数字输入框（Entry）
默认值6
单位—（整数）
功能说明正多边形边数（≥3），如 3（三角形）、4（方形）、5、6（六边形）、8（八边形）…
操作方法仅正多边形可编辑。
注意事项非正多边形时置灰；输入非法整数时应用尺寸报错。

4.2.7 L1 方向（横向 / 竖向）

控件类型单选按钮组（Radiobutton × 2）
选项横向（默认） / 竖向
功能说明确定 L1 在工件上的放置方向，同时决定 NC 的 C 轴相位与预览方向：
横向L1 水平放置，0° 在工件右侧（CAD +X 方向），末行 C360 点位于 0° 方向（右侧）
竖向L1 竖直放置，C 轴相位旋转 90°，0° 在屏幕顶部，末行 C360 点位于 270° 方向（左侧）
操作方法点击「横向」或「竖向」；切换后预览立即旋转 90°，C360 X 值实时刷新。
注意事项该方向与 NC 程序相位完全一致，切换后生成的程序相位随之变化。

4.2.8 「应用尺寸 / 重新预览」按钮

控件类型蓝色按钮
功能说明校验并应用当前全部尺寸参数，随后重绘预览、刷新磨削时间/圈数估算，并写入日志。
校验规则① D、L2 必须为正数；② 腰形/圆角矩形 L1 必须为正，L1<L2 自动对调；③ 正多边形 R 必须 ≥0 且小于 L2/2。
操作方法修改任何尺寸后点击本按钮（或直接修改补偿实时预览）。
注意事项校验失败弹出「参数错误」并说明原因，不应用修改。

4.2.9 形状说明文字

控件类型只读文本（自动换行）
功能说明随所选形状显示对应工艺说明。
内容腰形：无说明；圆角矩形：「已接入 NC 生成（切点跟踪等距磨削，与腰形同算法），尺寸按 L1×L2、圆角 R」；正多边形：「内切圆 L2（对边距离）控形、N 边数可设、外圆料用 D；尖尖由 R 圆角控制（R=0 为尖角，R 必须小于 L2/2）；补偿用 L2 补偿（comp2）等向缩放」。

4.3 ③ 补偿（手动输入，负=磨小，正=磨大）

4.3.1 L1 补偿

控件类型数字输入框（Entry）
默认值-0.4530
单位mm
功能说明长度方向等向补偿：负值使磨削轮廓缩小（成品偏小），正值放大。补偿计入轮廓计算（补偿后轮廓直接显示在预览中）。
操作方法直接输入；修改后预览立即重绘（无需点按钮）。
注意事项生成程序时补偿计入尺寸计算；常见场景为负值（热膨胀/测量偏差补偿）。

4.3.2 L2 补偿

控件类型数字输入框（Entry）
默认值-0.4730
单位mm
功能说明宽度/内切圆方向等向补偿；正多边形用 L2 补偿（comp2）等向缩放整个轮廓。
操作方法同 L1 补偿；实时重绘。

4.4 ④ 砂轮模块（修改砂轮直径需密码）

4.4.1 砂轮当前实际直径

控件类型数字输入框（Entry，默认锁定）

4.4.3 粗磨用时（时:分:秒）

控件类型只读文本（青色显示）

8 NC 程序生成与输出

8.1 生成流程

1
确认对话框
点击「▶ 生成 NC 程序」弹出：显示当前砂轮直径；提示生成完成后将自动减去修磨量更新砂轮大小；确认参数无误后点击「是」。
2
高风险确认（仅勾选正向进刀时）
已勾选「X 正向进刀」时再次弹窗：请再次确认本机确实是 X 越大越往工件切，且修砂轮进退刀方向已按正向联动；选错方向会直接撞机。
3
计算
软件计算轮廓、三阶段走刀、修砂轮调度、磨损补偿；统计修砂轮总次数与砂轮损耗。
4
选择输出目录
弹出目录选择框（默认 output 目录）；取消则写入当前目录下的 output 文件夹（自动创建）。
5
写出文件
日志依次记录：【系统·模式】平面 G18 → 已写出 文件路径（N 行）。
6
砂轮自动更新 + 完成
砂轮直径自动变为 新直径（减去本次修磨量）；日志记录「本次共修砂轮 N 次，磨掉 X mm，砂轮直径：a → b」；弹出完成对话框。

8.2 输出文件与三阶段磨削

阶段作用说明
粗磨分层进刀，快速去除大部分余量每层进刀量=粗磨进刀量；首刀从毛坯直径起刀；每圈最大切削量不超过设定值
圈边每圈进刀，逼近成品轮廓进刀量=圈边进刀量；到精磨预留余量为止
光磨无进给抛光按光磨圈数沿成品轮廓光磨，保证表面质量与尺寸
轮廓生成采用切点跟踪等距磨削（砂轮半径等距偏置），任何形状（腰形/圆角矩形/正多边形）均不过切、不欠切、不磨削超过圆料；正多边形角部按 R 圆角圆弧磨削。

9 安全注意事项

1. X 正向进刀方向：「我确认本机是 X 正向进刀」必须确认无误后才勾选，选错方向会直接撞机；修砂轮进退刀方向随此联动。
2. 直径/半径编程口径：X 轴直径/半径编程必须与机床一致，差一倍会造成磨削深度错误。
3. 砂轮直径：修改砂轮直径需密码（123456）；输入不实直径会导致磨损补偿错误。生成后软件自动减去修磨量，请勿重复手动修改。
4. 密码管理：砂轮直径与程序代码共用密码 123456；请由工艺负责人保管。
5. 正多边形参数：R 必须 ≥0 且小于 L2/2；D 必须大于成品最大外形 + 留量，否则会磨超圆料或无法生成。
6. 输出系统匹配：切换数控系统前确认机床型号；老固件选 LNC 老固件（不支持 MAX），新固件选 LNC 新固件。
7. 程序代码：进刀/修砂轮/退刀程序为机床安全指令（G54G90 等），修改需密码，勿删必需指令。
8. 修砂轮调度：精磨前修砂轮与定时修砂轮次数合理设置，避免精磨中途砂轮磨损超差。
